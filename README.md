People Cards – React

A simple and interactive React application for managing people information cards.

Features

* Display people information using reusable React components
* Search people by name
* Add new people
* Delete people
* Show and hide hobbies
* Form validation for name and age
* Responsive and clean user interface

Technologies

* React
* JavaScript
* HTML
* CSS
* React Hooks (useState)
* Array methods (map, filter)

Project Structure

src/
├── components/
│   └── Card.js
├── App.js
├── App.css
└── index.js

How to Run

Clone the repository and install the dependencies:

npm install

Start the development server:

npm start

The application will run at:

http://localhost:3000

Testing

The project can be tested using:

npm test

What I Practiced

This project helped me practice React fundamentals including components, props, state management, event handling, list rendering, filtering, form inputs, validation, and basic testing.
